# ADR-0001 — Product identity: Evidentia

**Status:** accepted · **Date:** 2026-09-18 · **Owner:** Clixite SRL

## Context
The product must have a distinctive English identity that communicates generative
visibility, trusted knowledge, answer-engine optimisation, enterprise governance and
European trust, without cheesy AI naming and without being a renamed "GEOFlow Europe".
No existing Clixite product name was present in the workspace.

## Shortlist
| Name | Signal | Concern |
|---|---|---|
| **Evidentia** | evidence, provenance, Latin/European register, legible in all EU languages | a genealogy desktop application uses the same name in an unrelated class; trademark clearance required before public launch |
| Attestia | attestation, trust | weaker link to content and visibility |
| Veridex | veracity, index | sounds like a pharmaceutical brand |
| Citelight | citations, discoverability | playful; weaker enterprise register |
| Answerbase | AEO literal | generic, descriptive, likely unregistrable |

## Decision
Name the product **Evidentia**. Full form: *Evidentia by Clixite SRL*.

- Positioning: *Governed generative visibility for European organisations.*
- One-liner: Evidentia makes authoritative organisations easier for humans and AI
  systems to discover, understand, verify, cite and trust — with governance built in.
- Vocabulary: Knowledge (sources, documents, claims, entities), Evidence, Readiness,
  Observatory (AI visibility measurement), Gate (governance/approval), Register
  (AI systems, models), Ledger (audit), Policy.
- Tone: precise, restrained, European, evidence-first; no superlatives without sources.
- Mandatory mark: **Built and maintained by Clixite SRL — Belgium**.

## Consequences
- Package scope `@evidentia/*`, CLI `evidentia`, skill name `evidentia`.
- Trademark search and registration are a pre-launch task for Clixite legal; until
  then the name is a working product name.
- Upstream inspiration (GEOFlow) is credited separately and accurately; Evidentia does
  not claim upstream authorship.
