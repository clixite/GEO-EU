# Release process

## Versioning

SemVer. `version` in root and package manifests, `VERSION` in the CLI, skill
`metadata.version` and `evals/expected-artifacts.json` move together.

## Checklist

1. `pnpm typecheck && pnpm test`
2. `node --test "skill/evidentia/evals/*.test.mjs"`
3. `node scripts/smoke.ts`
4. `node packages/cli/bin/evidentia.mjs evals run --db :memory: --out dist/evals-report.json`
5. `pnpm build && pnpm test:e2e`
6. `pnpm audit --audit-level=high`
7. `node scripts/licenses.ts`
8. `node scripts/sbom.ts --out dist/sbom.cdx.json`
9. `gitleaks detect --source . --no-banner --redact`
10. Update CHANGELOG.md, docs/BUILD_STATE.md, website changelog page.
11. Tag: `git tag -s vX.Y.Z -m "Evidentia X.Y.Z"` (signed tag).
12. Package the skill: `git archive --format=zip -o dist/evidentia-skill-X.Y.Z.zip HEAD:skill/evidentia`
    and the repository: `git archive --format=tar.gz -o dist/evidentia-X.Y.Z.tar.gz vX.Y.Z`.
13. Checksums: `sha256sum dist/* > dist/SHA256SUMS`; sign `SHA256SUMS`.
14. GitHub release with: release notes, `SHA256SUMS(.sig)`, SBOM, evals report,
    Playwright report, skill zip.

## Release manifest

`dist/release-manifest.json` (generated by CI on tags — planned 1.1): version,
commit, build time, artefact hashes, SBOM serial number, test counts.

## Support policy

Security fixes for the current major version for ≥ 24 months. Supported
Node.js: current LTS ≥ 24.

## Post-release

Update docs/BUILD_STATE.md, open the next milestone, monitor CI on `main`.
